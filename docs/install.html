Install Kavii.

A tiny menu-bar butterfly for macOS 13 Ventura and newer. No account, installer, or background service required.

Open latest release ↗ View source ↗

Install

  1. Open the latest release and download arm64 for an Apple Silicon Mac (M1 and newer), or x86_64 for an Intel Mac.
  2. Double-click the ZIP, then drag LilButterfly.app into your Applications folder.
  3. Open the app and look for the butterfly in your menu bar. Click it and choose Show a butterfly now to try it.

First launch warning

The downloadable build is not currently notarized with an Apple Developer ID. If macOS blocks it, Control-click LilButterfly.app in Applications, choose Open, and confirm. If needed, go to System Settings → Privacy & Security → Open Anyway.

Safety note: use releases from this repository. The source and release history are public, and Kavii does not ask for an account.

Updates

At launch, Kavii checks the public GitHub Releases endpoint. When a newer version is available, the menu-bar icon shows 🦋↑ and the menu shows Update available. Click it to open the official download page.

The app never replaces itself silently. Download the new ZIP, quit the old app, replace the copy in Applications, and open it again. Your settings remain in ~/Library/Application Support/LilButterfly/config.json.

Start at login

After moving Kavii to Applications, open System Settings → General → Login Items and add LilButterfly.app under Open at Login.

Something not working?

  • Use Show a butterfly now and confirm the app is not paused.
  • For Google Meet in Chrome or Safari, use Pause during the meeting. Browser-tab detection is intentionally not enabled.
  • To reset settings, quit Kavii and remove ~/Library/Application Support/LilButterfly/config.json.

For the maintainer

Push a semantic version tag to build both Mac architectures and publish a release automatically:

git tag v1.0.1 && git push origin main --follow-tags

The workflow in .github/workflows/release.yml creates the ZIPs and generates release notes. Enable the website from repository Settings → Pages → Deploy from a branch → main /docs.
