Install Butterfly

easy installation

Just copy and paste.

1

Open Terminal

Press ⌘ Command + Space, type Terminal, then press Return.

2

Copy this command

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/gajeradhrumil38/lil-butterfly-mac/main/scripts/install.sh)"
3

Paste it and press Return

Terminal may ask for your Mac password. Type it and press Return. Nothing appears while you type—that is normal.

🦋

That’s it.

Butterfly opens automatically. Look for the 🦋 at the top of your screen and choose Show a butterfly now.
